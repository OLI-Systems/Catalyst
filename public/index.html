Catalyst Pilot

Your IDE sidekick. Configure what it watches for and when it speaks up.

HOW IT WORKS

Catalyst Pilot runs a quiet background loop — it watches git state, build output, and your edits, then surfaces what's actionable. It can also execute IDE commands when you ask, like "build it" or "switch to main".

On Windows/Linux the single-key shortcuts (Open repo, Switch branch, etc.) fire only when the terminal isn't focused, so keys like Ctrl+O still reach the CLI. The Command Palette (Ctrl+Shift+P) works from anywhere.
